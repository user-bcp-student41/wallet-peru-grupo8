# Wallet Peru - Grupo 8

Repositorio del proyecto Wallet Peru del Grupo 8.

## Estructura

- `docs/`: alcance, historias de usuario, arquitectura, decisiones y guion de demostración.
- `backend/`: aplicación y pruebas del backend.
- `frontend/`: aplicación web.
- `mock-payment-provider/`: proveedor de pagos simulado.
- `tests/`: pruebas de aceptación y datos de prueba.

## Estado

Este repositorio contiene la estructura inicial del proyecto. Las tecnologías,
requisitos y comandos de ejecución se documentarán cuando se definan.
